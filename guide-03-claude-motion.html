피사체/배경 완벽 분리

단일 영상의 인물과 배경을 분리해 피사체 등 뒤에 텍스트와 그래픽을 배치합니다.

로컬 AI 무료 구동

외부 유료 API가 아닌 내 PC 자원을 활용하여 오픈소스 추적 모델을 무료로 돌립니다.

동적 모션 트래킹

제품의 특정 포트나 움직이는 물체를 자연스럽게 따라다니는 이펙트를 만듭니다.

STEP 1 기초 환경 세팅 및 모델 준비
중요: 웹이나 가상 머신 환경이 아닌, 내 컴퓨터의 물리적 자원(GPU)을 직접 끌어다 쓰는 'Claude Code (로컬 CLI)'를 반드시 사용해야 합니다[cite: 6].
  1. 스킬 모듈 확보: 오픈소스로 공유되고 있는 영상 분석 전용 스킬 단일 파일을 복사하여 프로젝트 내부에 구성합니다[cite: 6].
  2. 독립 폴더 격리: 바탕화면 등에 '모션 그래픽 전용 빈 폴더'를 생성합니다. 이는 클로드의 이전 작업 기억과 프롬프트 셋팅이 새 영상 작업과 꼬이지 않도록 보호하는 필수 단계입니다[cite: 6].
  3. 로컬 환경 실행: 클로드 코드를 실행하고, 방금 생성한 빈 폴더를 워크스페이스로 지정하여 깨끗한 상태에서 새 프로젝트를 시작합니다[cite: 6].
STEP 2 소스 업로드 및 자동 추적 구동
  1. 최적 모델 선택: 프레임 분석과 정교한 모션 렌더링 스크립트 작성에 가장 뛰어난 추론 능력을 보이는 'Opus 5.5 (Medium)' 이상의 모델로 환경을 맞춥니다[cite: 6].
  2. 소스 주입: 1단계에서 준비한 '스킬 파일'과 편집할 '원본 영상'을 로컬 채팅 인터페이스에 함께 첨부합니다[cite: 6].
  3. 자동 분석 실행: "첨부한 영상의 피사체와 배경을 레이어로 분리해 줘"라고 지시합니다. 클로드 코드가 백그라운드에서 Meta의 SAM 2 모델 등을 자동으로 로드하여 누끼 추적을 수행합니다 (PC 사양에 따라 수 분 소요)[cite: 6].
STEP 3 효과 적용 및 일괄 처리 (효율화 팁)
  1. 입체 뎁스 연출: 레이어 분리가 완료되면 "분리된 배경 레이어의 명도를 어둡게(Dim) 낮추고, 피사체 바로 뒷공간에 커다란 하얀 텍스트를 배치해 줘"라고 지시하여 세련된 입체감(Depth)을 만듭니다[cite: 6].
  2. 디테일 트래킹: 전자기기 리뷰 영상이라면 "기기 뒷면의 HDMI 포트 좌표를 지속적으로 트래킹해서, 가리키는 선과 설명 텍스트가 포트를 쫓아다니게 해줘"라고 추가 지시하여 동적인 화면을 완성합니다[cite: 6].
  3. HTML 씬 분할 꼼수: 시간을 획기적으로 줄이는 비법입니다. "영상을 여러 씬(Scene)별로 쪼갠 HTML 프리뷰 페이지와, 씬마다 코멘트를 남길 수 있는 입력창을 만들어줘"라고 요청하세요. 화면을 보며 씬별 수정 사항을 한 번에 타이핑해 제출하면, 클로드가 알아서 일괄(Batch)로 편집을 수행합니다[cite: 6].
