1. 클로드 무료 버전(Sonnet 5.5) 기초 세팅 및 정보 주입
핵심 원리: 유료 결제나 프로(Opus) 모델이 없어도, 무료로 풀려있는 Sonnet 5.5 모델만으로도 브라우저 코딩 기반의 훌륭한 2D 모션그래픽을 만들 수 있습니다.
  • 키워드 주입: 복잡한 기획서는 필요 없습니다. "나의 7년 차 커머스 크리에이터 이력, 리뷰 800개, 채널 2개 운영 중이라는 내용을 담아서 모션그래픽으로 자기소개 만들어 줘"라고 한 줄만 던집니다.
  • HTML 애니메이션 자동 생성: 클로드는 프리미어 타임라인이 아닌 웹 페이지 코딩(HTML/CSS/JS) 방식으로 영상을 구성합니다. 숫자가 1에서 800으로 다이내믹하게 올라가는 카운트업 효과, 연도별 타임라인 분할, 화면 전환 효과를 사용자가 지시하지 않아도 스스로 기획하고 코딩하여 보여줍니다.
2. 웹 오디오와 대화형 텍스트 수정
  • SFX(효과음) 자동 생성: 음악이나 효과음 파일이 없어도 괜찮습니다. "효과음과 배경음악 넣어 줘"라고 지시하면, 클로드가 웹 오디오 API를 활용해 화면이 전환될 때 나는 '스윽' 소리나 글자가 써질 때 나는 '타이핑 소리'를 코드로 쳐서 직접 구현해 냅니다. (보유한 MP3 음원이 있다면 첨부하여 적용시킬 수도 있습니다.)
  • 레이아웃 자동 계산: 텍스트를 수정할 때 에프터이펙트처럼 키프레임을 만질 필요가 없습니다. "마마루시아로 이름을 바꿔 줘"라고 하면 글자 수가 늘어난 것에 맞춰 폰트 크기와 여백, 레이아웃을 클로드가 스스로 재계산하여 밸런스를 맞춥니다.
3. 최대의 마법: HTML을 MP4로 직접 렌더링하기
  • 화면 녹화의 한계 극복: 보통 클로드에서 만들어진 결과물을 다운로드하면 `.html` 웹 파일이 나옵니다. 이걸 영상으로 쓰려면 브라우저를 띄우고 OBS 등으로 화면 녹화를 해야 하는 번거로움이 있습니다.
  • 마법의 프롬프트: 이때 화면 녹화 대신 클로드 채팅창에 "바로 영상으로 다운받을 수 있게 해 줘"라고 강력하게 지시하세요.
  • 자체 MP4 추출: 클로드가 자신의 백엔드 가상 환경 내에서 해당 HTML 애니메이션을 프레임 단위로 캡처하고, 효과음 오디오를 먹싱(Muxing)하여 1080p 해상도의 순수 `.mp4` 파일로 렌더링해 줍니다. 수 분의 대기 후, 클릭해서 바로 다운받을 수 있는 파일 링크를 뱉어냅니다.
4. 오답노트: 폰트 깨짐과 무료 버전의 한계
[생산성 인사이트 및 실무 팁]
비싼 외주나 유료 결제 없이 기획, 렌더링, 영상 추출까지 원스톱으로 0원에 끝내는 파이프라인이지만, 무료 버전을 이용할 때는 반드시 '1일 사용량'을 염두에 두어야 합니다.
  • 폰트 뭉개짐(Aliasing) 이슈: HTML 캡처를 통해 MP4로 변환되는 과정에서 특정 한글 폰트의 획이 뭉개지거나 깨져 보이는 현상(예: '루' 글자)이 발생할 수 있습니다. 결과물을 즉시 검수하고 "구글 웹폰트 Noto Sans KR을 적용해서 다시 렌더링 해" 같은 보완 지시가 필요합니다.
  • 일일 사용량 제한(Rate Limit): 이러한 수정 지시와 MP4 렌더링 과정을 반복하다 보면 무료 버전의 1일 사용량 제한(메시지 횟수 제한)에 도달해 작업이 멈출 수 있습니다. 따라서 한 번 프롬프트를 칠 때 여러 수정 사항을 모아서 지시하는 요령이 필요합니다.
