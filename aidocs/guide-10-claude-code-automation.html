STEP 1 3분할 워크스페이스 세팅과 필수 요금제
중요: 이 파이프라인을 구축하려면 일반 무료 버전이 아닌 '클로드 프로(Claude Pro)' 이상의 요금제가 필수적으로 요구됩니다[cite: 10].
  1. VS Code 통합 환경 구축: 비주얼 스튜디오 코드(VS Code)를 설치하고, 왼쪽 확장(Extensions) 탭에서 'Claude Code'를 검색해 플러그인을 설치합니다[cite: 10]. 이후 계정을 로그인하여 로컬 권한을 연동합니다.
  2. 3구역 분할 이해: 화면은 크게 세 영역으로 나뉩니다. 왼쪽은 프로젝트의 모든 파일과 폴더를 볼 수 있는 '사물함', 중앙은 파일 내용을 확인하는 '작업대', 오른쪽은 클로드와 대화하고 명령을 내리는 AI 패널인 '일터'입니다[cite: 10]. 코딩을 몰라도 우측 일터에서만 자연어로 지시하면 AI가 좌측과 중앙을 알아서 조작합니다.
  3. 독립 폴더 할당: 바탕화면 등에 '콘텐츠 리포트' 같은 빈 폴더를 생성하고 VS Code에서 엽니다[cite: 10]. 다른 작업과 꼬이지 않도록 독립된 환경을 주는 것이 첫걸음입니다.
STEP 2 'claude.md' 헌법 제정과 권한 제어 (Edit vs Architect)
  1. 모드 전환의 이해: AI 패널 하단에는 작업 모드를 설정할 수 있습니다. 'Edit(크 에딧)' 모드는 클로드가 파일을 수정하기 전 "혹시 이거 바꿔도 될까요?"라며 매번 허락을 구하는 모드이며, 'Architect(아키텍트)' 모드는 구조적인 설계를 주도하는 모드입니다[cite: 10]. 초기 구축 시에는 모드를 적절히 변경하며 통제력을 갖춰야 합니다.
  2. 설계도 claude.md 작성: AI는 명확한 매뉴얼이 없으면 우왕좌왕합니다[cite: 10]. 폴더에 `claude.md` 파일을 만들고, AI의 역할, 업무 처리 순서, 그리고 절대 쓰면 안 되는 금지어와 말투를 헌법처럼 박아두어야 흔들리지 않는 자동화가 작동합니다[cite: 10].
STEP 3 Play MCP 및 외부 API 연동 디버깅
  1. Play MCP 장착: 로컬 컴퓨터 안의 데이터만 다루는 것을 넘어, 외부 세계와 소통하기 위해 MCP(Model Context Protocol)를 활용합니다[cite: 10]. 카카오에서 만든 'Play MCP'를 연동하면 네이버 뉴스 검색, 유튜브 트렌드 데이터, 카카오톡 '나와의 채팅방(나채방)' 전송 기능을 AI가 끌어다 쓸 수 있습니다[cite: 10].
  2. 자기 수정 루프 (Ping-Pong): API 키를 연동하고 실행할 때 에러가 나면 사람이 고치지 않습니다[cite: 10]. 에러 메시지를 그대로 복사해 클로드에게 "이거 안 돼. 왜 안 돼? 다시 고쳐"라고 지시하면 코드를 스스로 수정하고 재실행합니다[cite: 10]. 이 디버깅 루프를 작동할 때까지 3~4번 반복하는 것이 핵심입니다.
STEP 4 무인 자동화 구축: GitHub & Routines
  1. GitHub 푸시: 컴퓨터 폴더 내에서 완벽하게 작동하는 코드를 완성했다면, 이를 GitHub Repository(원격 저장소)에 Push합니다[cite: 10]. '솔로 데일리 브리핑'과 같이 이름을 짓고 `prompt.md` 파일 등을 업로드합니다[cite: 10].
  2. 클라우드 스케줄링: 로컬 환경의 단점(컴퓨터를 꺼두면 작동 안 함)을 극복하기 위해 클라우드 스케줄러(Routines 등)를 세팅합니다. "매일 아침 8시에 이 레포지토리를 클론하고 prompt.md대로 실행해"라고 트리거를 겁니다[cite: 10].
  3. 시간의 환수: 이제 노트북 전원을 끄고 여행을 가도, 매일 8시가 되면 AI가 뉴스를 긁어 트렌드를 분석하고 카카오톡으로 10개의 브리핑 리포트를 쏴줍니다[cite: 10]. 수동 반복 업무를 AI에게 던지고, 남은 시간은 진짜 낭만적이고 창조적인 '인간만의 일'에 투자하세요[cite: 10].
