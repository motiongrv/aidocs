STEP 1 모드(Mods)의 기본 개념과 공식 제공 기능
핵심 원리: '모드(Mods)'란 클로드 코드 사용 환경에 나만의 유틸리티 UI와 자동 실행 규칙(훅)을 덧붙여 기존 터미널을 극도로 최적화하는 확장 아키텍처입니다.
  1. 토큰 웨더 (Token Weather): 대화창 하단에 현재 컨텍스트 윈도우 잔여량을 시각화하는 UI 모드입니다. 여유가 있을 땐 맑음 아이콘으로 표시되다가 한계에 다다를수록 비나 폭풍우 아이콘으로 변하여 직관적인 모니터링을 돕습니다.
  2. 블라스트 레디어스 (Blast Radius): 파일이나 폴더를 삭제하는 등 시스템적으로 치명적일 수 있는 명령어가 감지되면, 실행되기 전 경고 패널을 띄우고 승인/취소를 묻는 강력한 안전장치 모드입니다.
  3. 리플레이어 터 (Replay-er): 바이브 코딩 중 세션을 유지하면서도 우측 패널을 통해 기존 코드의 변경 사항 이력을 간편하게 추적하고 확인할 수 있는 이력 관리 모드입니다.
STEP 2 4단계 훅(Hook)을 통한 권한 가로채기와 통제

모드는 내가 프롬프트를 치지 않아도 특정 시점에 자동으로 발동되는 '훅(Hook)' 메커니즘을 기반으로 작동합니다. 이를 통해 AI의 행동을 완벽하게 통제할 수 있습니다.

  • 1. Prompt (처리 전 가로채기): 사용자가 프롬프트를 입력하면 AI가 처리하기 직전에 가로채어, 숨은 의도를 분석하거나 AI에게 전달할 작업 규칙(맥락)을 자동으로 삽입해 줍니다.
  • 2. Before (도구 호출 전 차단): AI가 스스로 판단하여 특정 도구(명령어 실행, 파일 수정 등)를 호출하기 직전에 발동합니다. 위험 요소를 사전 차단하거나 관리자의 승인을 강제할 때 활용됩니다.
  • 3. After (도구 호출 후 변환): AI가 도구를 사용하여 코드를 변경한 직후 발동합니다. 변경된 결과를 내가 지정한 특정 리포트 포맷이나 UI 패널 형식으로 변환하여 출력하게 만듭니다.
  • 4. Stop (응답 완료 후 정리): AI의 한 턴 답변이 완전히 끝나는 시점에 발동합니다. 이때 최종 요약을 띄우거나, 컨텍스트 용량 등의 UI 패널을 최신화합니다.
STEP 3 코딩 제로 커스텀 모드 창조 및 실전 팁
  1. 공식 블로그 샘플 훔치기: 내가 직접 코딩할 필요가 없습니다. 클로드 공식 블로그에 배포된 '모드 생성 샘플 코드'를 통째로 복사해서 클로드 코드 채팅창에 붙여넣고 "이 구조를 참고해서 내가 원하는 특정 모드로 개조해 줘"라고 바이브 코딩을 지시하세요.
  2. 학습 노트 모드 (Learning Note): 바이브 코딩으로 자동 생성된 코드가 왜 이렇게 작성되었는지 초보자는 이해하기 어렵습니다. AI가 코드를 수정할 때마다 '왜 이 코드를 만들었고, 변경의 논리가 무엇인지' 우측 패널에 상세히 해설해 주는 학습용 모드를 추가하면 실력 향상에 큰 도움이 됩니다.
  3. 캐시 워치 (Cash Watch): 클로드는 1시간 동안의 세션을 캐시로 유지하여 입력 토큰 비용을 아낍니다. 하단 패널에 '무료 캐시 세션 타임 잔여 시간'과 '현재까지 발생한 대화 누적 예상 비용'을 실시간으로 띄우는 모드를 장착하여 치명적인 토큰 낭비를 예방하세요.

[지식 베이스 분석 메모]
클로드 코드의 최신 기능인 '모드(Mods)' 아키텍처 심화 분석 가이드. 사용자는 기존 UI를 덮어쓰거나 새로운 커스텀 패널(토큰 웨더, 캐시 워치, 바이브 코딩 학습 노트 등)을 터미널 내에 자유롭게 띄울 수 있음. 이 모드는 AI의 특정 실행 지점(Prompt, Before, After, Stop)을 가로채는 4단계 '훅(Hook)' 메커니즘을 통해 작동하며, 위험 명령어 실행 시 사전 승인(Blast Radius)을 받거나 특정 포맷으로 보고를 강제할 수 있음. 공식 블로그의 템플릿을 복붙하여 바이브 코딩 방식으로 모드를 자체 생성/개조하는 전략이 가장 효율적임.
